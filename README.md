FourSeafile
===========

Unofficial [Seafile](https://www.seafile.com/en/home/ "Seafile") client. Seafile is private or public enterprise ready cloud at your choice with built-in file encryption and team collaboration. 
Made possible with [renber/SeafClient](https://github.com/renber/SeafClient "renber/SeafClient") library (which I also contributed to).
